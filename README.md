# Королевство Флоптропика — Telegram RPG Bot

Рабочая модульная MVP-версия бота, адаптированная для Render.

## Что уже реализовано

- регистрация персонажа;
- загрузка ровно одного портрета персонажа через Telegram `file_id`;
- создание дома и загрузка ровно одного изображения дома;
- профиль персонажа;
- карточка дома;
- ежедневная тренировка;
- работа на 2 часа, не более двух раз в сутки;
- PostgreSQL;
- золото и журнал транзакций;
- инвентарь;
- магазин без рынка между игроками;
- сокращённая экипировка: оружие, броня, амулет, питомец;
- профессии;
- фракции;
- NPC: крестьянин и стражник;
- базовые административные команды;
- HTTP health-check для Render;
- модульная структура проекта.

## Важно о токене

Никогда не вставляйте токен в код и не загружайте его на GitHub. Создайте новый токен через BotFather и добавьте его в Render как секрет `BOT_TOKEN`.

## Развёртывание на Render

1. Распакуйте архив.
2. Создайте приватный репозиторий GitHub.
3. Загрузите в него содержимое папки проекта.
4. В Render откройте **New → Blueprint**.
5. Подключите репозиторий.
6. Render прочитает `render.yaml` и создаст:
   - Web Service;
   - PostgreSQL.
7. В переменных окружения укажите:
   - `BOT_TOKEN` — новый токен;
   - `ADMIN_IDS` — Telegram ID администраторов через запятую.
8. Нажмите Deploy.

`DATABASE_URL` подключается автоматически через Blueprint.

## Как узнать Telegram ID

Можно временно написать боту `@userinfobot` или другому безопасному ID-боту. Затем внесите число в `ADMIN_IDS`.

## Особенности Render

Проект запускается как Web Service. FastAPI отвечает на `/` и `/health`, а Telegram-бот работает параллельно через long polling.

Render может перезапускать бесплатный сервис. Состояние не теряется, потому что:
- игровые данные находятся в PostgreSQL;
- изображения хранятся как Telegram `file_id`.

- 12–20 энергии ремонта;

## Устойчивые таймеры Render

Версия v4.1 не полагается на непрерывный отсчёт в оперативной памяти.

Все сроки хранятся в PostgreSQL:
- `response_deadline` — окончание десятиминутного ожидания;
- `guard_finish_at` — окончание боя стражников;
- `last_attack_date` — дата последнего ежедневного нападения.

Добавлена защищённая HTTP-точка:

```text
/tasks/run?key=CRON_SECRET
```

При каждом вызове она:
1. создаёт положенные ежедневные нападения;
2. обрабатывает истёкшие 10 минут;
3. завершает готовые бои стражников;
4. отправляет уведомления игрокам.

### Переменная Render

Добавьте в Render:

```text
CRON_SECRET=длинная_случайная_строка
```

Например, создайте строку длиной не менее 32 символов. Не публикуйте её в GitHub.

### Настройка cron-job.org

1. Откройте сайт `cron-job.org`.
2. Создайте бесплатный аккаунт.
3. Нажмите **Create cronjob**.
4. В поле URL вставьте:

```text
https://ВАШ-СЕРВИС.onrender.com/tasks/run?key=ВАШ_CRON_SECRET
```

5. Поставьте выполнение каждые 5 минут.
6. Включите сохранение и уведомление об ошибках.

Первый запрос после сна Render может выполняться дольше из-за холодного запуска.
Следующий запуск обработает все сроки, поэтому игровые данные и награды не теряются.

### Проверка

Откройте в браузере:

```text
https://ВАШ-СЕРВИС.onrender.com/tasks/run?key=ВАШ_CRON_SECRET
```

При успехе вернётся JSON примерно такого вида:

```json
{"status":"ok","processed_at":"2026-07-11T12:00:00+00:00"}
```

Неверный ключ возвращает ошибку 403.

## Версия 7.0 — Duel Arena & In-App Theme Studio

### Дуэли в Mini App

Добавлена полноценная пошаговая PvP-дуэль внутри Mini App:

- выбор соперника из списка граждан;
- фотографии обоих персонажей;
- отображение уровня, титула, рейтинга, побед и поражений;
- выбор боевого стиля;
- полосы HP, маны и выносливости;
- действия: атака, магия, защита, уклонение, критический удар и зелье;
- журнал боя;
- автоматическое обновление состояния каждые несколько секунд;
- рейтинг и награды после победы.

Расчёт каждого атакующего действия устроен по правилу:

- 50% результата дают уровень, характеристики и экипировка;
- 50% результата формирует случайное значение.

Поэтому развитый персонаж получает преимущество, но более слабый игрок всё равно может победить.

### Боевые стили

- Берсерк — больше урона, меньше защиты;
- Страж — усиленная защита, сниженный урон;
- Магистр — усиленная магия;
- Дуэлянт — повышенные мобильность и уклонение.

### Кастомизация прямо в Mini App

У создателя появляется плавающая кнопка `⚙` над нижней навигацией.
Она видна только Telegram ID, указанным в `ADMIN_IDS`.

В студии можно загружать:

- фоны всех разделов;
- логотип приложения;
- текстуру карточек;
- рамки героя и дома;
- фон дуэльной арены;
- рамку бойцов;
- изображение VS;
- иконку самой кнопки кастомизации.

Файл отправляется серверу из Mini App, бот сохраняет его в Telegram и записывает `file_id` в PostgreSQL. После загрузки оформление применяется без редактирования кода.


## Версия 7.1 — Design Studio

Внутри Mini App студия оформления теперь поддерживает три действия для каждого элемента:

- `📤 Загрузить` — выбрать новое изображение;
- `👁 Просмотр` — открыть изображение на весь экран;
- `🗑 Удалить` — удалить сохранённый `file_id` из PostgreSQL.

Также в студию добавлен блок «Мои изображения»:

- портрет героя;
- фотография владения.

Их можно загрузить через личный чат, просмотреть в Mini App или удалить. После удаления в разделах «Герой» и «Владение» снова появляется кнопка загрузки.

Физические изображения по-прежнему хранятся на стороне Telegram. Бот удаляет только ссылки `file_id` из своей базы данных, после чего изображения больше не используются приложением.


## Версия 7.5 — Зал Предсказаний

Добавлен новый раздел Mini App:

```text
🔮 Зал Предсказаний
```

### Возможности

- встроенная стандартная колода из 78 карт;
- открытая общая галерея авторских карт игроков;
- загрузка своей карты с изображением и значениями;
- все пользовательские карты автоматически видны всем гражданам;
- один вопрос и одно предсказание в сутки;
- выбор одной из трёх закрытых карт;
- прямое и перевёрнутое положение;
- сохранение истории раскладов;
- использование стандартных и пользовательских карт в ежедневных раскладах;
- отдельные фон, рубашка и иконка раздела в студии дизайна.

### Открытая галерея

Приватных карт нет. Любая карта, которую игрок добавляет через Mini App,
появляется в общей галерее и может участвовать в раскладах других игроков.

### Оформление

Создатель может заменить через студию:

- `tarot_bg` — фон Зала Предсказаний;
- `tarot_back` — рубашку закрытых карт;
- `icon_tarot` — иконку раздела.

### Предупреждение

Предсказания являются игровой интерпретацией для развлечения и размышления.
Они не заявляются как достоверный прогноз реальных событий.


## Версия 7.6 — Владения, NPC и монстры

### Неограниченные расклады Таро

Ограничение «один расклад в сутки» удалено. Игрок может задавать новые
вопросы и получать предсказания сколько угодно раз. Все результаты продолжают
сохраняться в истории.

При первом запуске обновления PostgreSQL автоматически удаляет старое
ограничение уникального ежедневного расклада.

### Нападения на владения

Раз в сутки на каждое владение нападает противник. Сила врага зависит от:

- уровня персонажа;
- уровня угрозы владения;
- типа противника;
- случайного коэффициента.

После каждого нападения уровень угрозы повышается, поэтому будущие враги
становятся сильнее.

Сообщение о нападении публикуется в общем чате и содержит кнопку:

```text
⚔ Открыть бой в Mini App
```

Владелец получает 10 минут для ответа. Бой проходит внутри Mini App в формате
тактической дуэли:

- атака;
- магия;
- защита;
- уклонение;
- критический удар;
- зелье.

На результат влияют характеристики героя, уровень, характеристики врага и
случайность.

### Комнаты владения

У каждого игрока автоматически появляется первая «Главная комната».

Количество доступных комнат:

```text
1 уровень — 1 комната
3 уровень — 2 комнаты
6 уровень — 3 комнаты
9 уровень — 4 комнаты
```

Игрок может загрузить изображение комнаты, название и описание.

### Ежедневная уборка

Владение нужно убирать один раз в день.

Варианты:

- убрать самостоятельно и получить немного опыта;
- отправить свободного крестьянина.

Если уборка пропущена, чистота снижается. При низкой чистоте дом начинает
терять прочность.

### NPC

В главном меню Mini App добавлен раздел:

```text
👥 NPC
```

Цены:

```text
Стражник — 80 золота
Крестьянин — 70 золота
```

#### Стражники

Если владелец не отвечает на нападение за 10 минут, свободные стражники
автоматически вступают в бой.

Время боя:

```text
1 стражник — 30 минут
каждый следующий — минус 3,5 минуты
минимальное время — 5 минут
```

Высокий уровень стражников дополнительно сокращает бой и повышает шанс победы.

Стражника можно отправить в Королевскую школу:

```text
стоимость — 10 золота
время — 4 часа
результат — повышение уровня
```

#### Крестьяне

Крестьянам доступны поручения:

- работа в поле;
- уборка владения;
- полив сада;
- чистка туалетов;
- отдых.

У каждого крестьянина есть усталость от 0 до 100. Тяжёлые поручения повышают
усталость. Отдых длится 8 часов и восстанавливает 70 единиц.

Крестьянин с усталостью 100 должен быть отправлен на отдых. Если он остаётся
истощённым более суток, он погибает. При попытке выполнять задание на пределе
также существует риск смерти от истощения.

### Кастомизация

В студию оформления добавлены:

- фон раздела NPC;
- иконка NPC;
- фон комнат;
- по три модели драконов;
- по три модели обычных монстров;
- по три модели аномалий;
- три модели стражников;
- три модели крестьян.

Модели NPC распределяются между купленными персонажами по очереди.


## Версия 7.6.2 — Библиотека обликов NPC

В студию оформления добавлено 120 слотов изображений:
по три облика для каждого из 40 типов NPC.

Доступны облики жителей, военных, магов, работников экономики,
государственных служащих, творческих персонажей, животных и легендарных NPC.

В студии появились фильтры:

```text
Все
Интерфейс
Облики NPC
```

Для каждого облика доступны:

```text
📤 Загрузить
👁 Просмотр
🗑 Удалить
```

Изображения сохраняются через Telegram `file_id` и не требуют хранения
файлов в репозитории или на диске Render.
